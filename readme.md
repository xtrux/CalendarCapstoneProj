# Calendar Capstone Project

A group calendar/availability web app built with Laravel and PostgreSQL.
this entire readme was generated by claude and slightly edited by me.

## Useful Commands

### Project Setup

```bash
composer install          # install PHP dependencies
npm install                # install JS dependencies
php artisan key:generate   # generate app encryption key (if needed)
```

### Database

```bash
php artisan migrate                  # run pending migrations
php artisan migrate:fresh            # drop all tables and re-run migrations (dev only, destroys data)
php artisan make:migration <name>    # create a new migration file
psql -h 127.0.0.1 -U calendar_app -d calendar_db   # open a psql shell to inspect the db
```

Inside `psql`:

```
\dt          # list all tables
\d <table>   # show a specific table's columns/constraints
\du          # list roles/users
\q           # quit
```

### Running the App

```bash
php artisan serve     # start local dev server (localhost:8000)
npm run dev            # run Vite for frontend assets, if using any JS/CSS build step
```

### Creating Things

```bash
php artisan make:controller <Name>Controller   # new controller
php artisan make:model <Name>                   # new Eloquent model
php artisan make:migration <name>                # new migration
php artisan make:test <Name>Test                 # new PHPUnit test (Feature test by default)
```

### Routes

```bash
php artisan route:list    # show every registered route, methods, and names
```

### Testing

```bash
php artisan test                        # run all tests
php artisan test --filter=<TestName>    # run one specific test
```

### Code Quality / CI

```bash
./vendor/bin/pint              # auto-fix code style issues
composer ci:check               # run the full CI check suite locally
```
## Database Schema

- **users** — accounts, credentials, lockout status, preferences
- **groups** — group name, invite code, admin user
- **group_members** — junction table linking users to groups, with role
- **events** — scheduled events tied to a group
- **availability** — per-user, per-group, per-date busy/free status
